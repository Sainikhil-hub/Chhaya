GhostPrint - IoT Device Identification via Traffic Fingerprinting
==================================================================

Core dependencies
-----------------
flask>=3.0.0
flask-socketio>=5.3.0
python-socketio>=5.10.0
eventlet>=0.35.0
scikit-learn>=1.3.0
numpy>=1.24.0
pandas>=2.0.0
joblib>=1.3.0

Optional (for live network capture)
------------------------------------
scapy>=2.5.0          # laptop-runnable packet capture (recommended)
pyshark>=0.6.0        # Wireshark/tshark wrapper (alternative)

Install
-------
pip install -r requirements.txt

For live capture on Windows, also install Npcap:
    https://npcap.com/
